# Von Shopify

| Prinzip | Wie wir es nutzen |
|---|---|
| Eigenes Problem zuerst | Einen Laden perfekt bedienen, dann generalisieren |
| Sharding-Key = shop_id | Jeder Laden ist natuerlich isoliert. Multi-Tenancy gratis. |
| Sandboxing fuer T1 | Fremder Code (T1 Entwickler) laeuft isoliert, kann Plattform nicht kaputt machen |
| Revenue trackt Kundenerfolg | Wir verdienen wenn der Laden verdient (Transaktionsgebuehr, nicht Abo) |
