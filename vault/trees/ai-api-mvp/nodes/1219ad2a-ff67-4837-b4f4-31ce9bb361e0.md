# Schicht 3 — Automatische Checks

Einmal einrichten, dann vergessen.

## Checks (Prioritaet)

| Was | Tool | Wann |
|---|---|---|
| Python Code-Style | Ruff (Linter + Formatter) | Tag 1 |
| Python Type-Check | pyright | Tag 1 |
| Keine Secrets | gitleaks Pre-Commit | Tag 1 |
| Tests bestehen | pytest | Tag 1 |
| API-Schema valide | OpenAPI Validator | Woche 2 |
| Frontend Linting | ESLint | Wenn Frontend kommt |
| Dependency Audit | pip-audit / npm audit | Woche 2 |

## Pre-Commit Hook

Laeuft vor jedem Commit automatisch:
- Ruff (Format + Lint)
- pyright (Type-Check)
- gitleaks (Secrets)
- pytest (Tests)

Wenn einer fehlschlaegt → Commit blockiert.
