# 3 Schichten — Sortierung aller Funktionen

## Der Test

Wenn ich es ENTFERNE — wer bricht?

- **ALLE brechen** → KERN
- **NUR MANCHE brechen** → MODULE
- **KEINER bricht** (ersetzbar) → ADAPTER

---

## KERN (ohne stirbt alles)

Wird einmal gebaut, laeuft immer, fuer alle Laeden gleich.

| Funktion | Warum KERN |
|---|---|
| Gateway (Hub-and-Spoke) | Einziger Eingang — ohne kommen keine Requests durch |
| Auth / Login | Ohne weiss niemand wer wer ist |
| Structured Keys (shop_id) | Ohne sieht Tony Michelles Daten |
| Queue pro Entity | Ohne blockiert ein kaputter Laden alle |
| Memory 4 Schichten | Ohne vergisst die AI alles sofort |
| Push Notifications | Jeder Laden braucht das — immer |
| Suche | Jede App braucht Suche — immer |
| Event-System | Ohne koennen Module nicht kommunizieren |

---

## MODULE (ohne fehlt ein Feature)

Wird pro Laden aktiviert/deaktiviert. Jedes Modul = ein Buero im Gebaeude.

| Modul | Wer braucht es | Wer nicht |
|---|---|---|
| Booking | Friseur, Arzt, Restaurant | Elektronik-Haendler |
| Payment | Fast alle | — |
| Chat / Messaging | Dienstleister | Mancher Laden |
| Bewertungen / Ratings | Alle mit Endkunden | B2B |
| QR-Code | Laeden mit Laufkundschaft | Online-only |
| Warenkorb / Cart | Shops mit Produkten | Dienstleister |
| Live-Tracking | Lieferdienste | Friseur |
| Favoriten / Wishlist | Shops | Dienstleister |
| Promo-Codes / Rabatte | Marketing-aktive Laeden | Manche |
| Social Feed | Community-orientierte | Manche |

---

## ADAPTER (austauschbar, keiner merkt es)

Verbindung zur Aussenwelt. Kann ersetzt werden ohne dass Module sich aendern.

| Adapter | Verbindet mit | Ersetzbar durch |
|---|---|---|
| Stripe | Zahlungsnetzwerk | PayMe, FPS, Adyen |
| Twilio | SMS / Telefon | Vonage, eigene SMS-Gateway |
| Firebase | Push Notifications | OneSignal, eigener Push |
| Google Maps | Karten / Standort | OpenStreetMap, Mapbox |
| Claude API | AI-Verstaendnis | GPT, Gemini, eigenes Modell |
| SendGrid | Email | Mailgun, SES |

---

## Analogie

```
KERN    = Verkehrsregeln     (gelten immer, fuer alle)
MODULE  = Spielregeln        (jedes Spiel hat andere, du waehlst)
ADAPTER = Uebersetzer        (Deutsch→Englisch, austauschbar)
```
