# Plattform-Strategie — API + Server ist Gold

## Gesetzte Entscheidung

```
BACKEND (API + Server)   ← Das Gold. Hier steckt alles drin.
         |
         v
    WEB FIRST            ← PWA, laeuft ueberall, kein App Store
         |
         v
    WRAP (Kapsel)        ← Android / iOS / Windows als Huelle um die Web-App
         |
         v
    NATIV (nur falls noetig) ← Nur fuer Hardware: Kamera, NFC, Bluetooth
```

---

## Warum diese Reihenfolge

| Stufe | Was | Warum |
|---|---|---|
| API + Server | Backend-Code, Datenbank, alle Regeln | Einmal bauen, alle Clients nutzen es |
| Web first | Vue.js PWA im Browser | 0 Installation, laeuft auf iPhone + Android + Desktop |
| Wrap | TWA (Android) / WKWebView (iOS) / Electron (Windows) | App Store Praesenz, Push, Icon auf Homescreen |
| Nativ | Swift / Kotlin nur fuer Hardware-Zugriff | Kamera-Scan, NFC-Payment, Bluetooth-Drucker |

---

## Was "API + Server ist Gold" bedeutet

Die Web-App, die Android-App, die iOS-App — alle rufen DIESELBE API auf.
Die Logik steckt NICHT in der App. Die App ist nur eine Fernbedienung.

```
iPhone-App  ───┐
Android-App ───┼──→  EINE API  ──→  EINE Datenbank
Browser     ───┤
WhatsApp-Bot───┘
```

Wenn die API steht, kann JEDER eine Oberflaeche bauen.
Das ist auch der T1-Hebel: Entwickler bauen eigene Clients gegen unsere API.

---

## Wann wird was gebaut

| Phase | Client | Grund |
|---|---|---|
| MVP | Web (PWA) | Zeigbar, testbar, kein Store noetig |
| Nach 10 Laeden | Android Wrap (TWA) | Play Store Praesenz |
| Nach 20 Laeden | iOS Wrap | App Store Praesenz |
| Nur bei Bedarf | Nativ-Teile | Hardware die Web nicht kann |

---

## Was Web NICHT kann (→ da wird nativ noetig)

| Feature | Web kann | Nativ noetig |
|---|---|---|
| QR scannen | Ja (Kamera-API) | Nein |
| Push Notifications | Ja (Service Worker) | Nein |
| NFC Payment | Nein | Ja |
| Bluetooth Drucker | Nein | Ja |
| Offline-Modus | Teilweise (Service Worker) | Besser nativ |
| Biometrie (Face ID) | Ja (WebAuthn) | Nein |

Fuer den MVP: **100% Web reicht.** Kein einziges nativ-Feature noetig.
