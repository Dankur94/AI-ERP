# Schicht 1 — CLAUDE.md

Wird automatisch bei jedem Start geladen. Definiert die Spielregeln.

## Enthaelt fuer Super-App:

- Was ist die Plattform (Kurzbeschreibung)
- Architektur-Entscheidungen (Orchestrator, 7 Schichten, Module)
- Regeln (Perfektion, Stabilitaet)
- Struktur (Ordner, wo was hin)
- Verbote (was wir NICHT bauen)
- Referenzen auf diesen Tree fuer Details

## Sub-CLAUDE.md pro Bereich:

```
super-app/
├── CLAUDE.md          ← Globale Regeln
├── api/CLAUDE.md      ← API-spezifisch
├── gateway/CLAUDE.md  ← Gateway-Regeln
└── modules/CLAUDE.md  ← Modul-Entwicklung Regeln
```
