# Qualitaetsprozess (CLAUDE.md, Handoff, Wartung)

Drei Gewohnheiten die Qualitaet sichern — ohne Disziplin.

---

## Gedaechtnis-Stack (3 Ebenen)

| Datei | Typ | Wann gelesen | Wann geschrieben |
|---|---|---|---|
| `CLAUDE.md` | Langzeit-Regeln | Session-Start (auto) | Bei Architektur-Entscheidungen |
| `docs/sessions/YYYY-MM-DD.md` | Kurzeit-Uebergabe | Session-Start | Session-Ende |
| `~/.claude/.../memory/MEMORY.md` | Gelerntes | Immer (auto) | Laufend (auto) |

### CLAUDE.md (vor dem Arbeiten)

- Wird automatisch geladen, 0 Aufwand
- Enthaelt: Was, Warum, Regeln, Verbote, Struktur
- Sub-CLAUDE.md pro Bereich (gateway/, core/, modules/)
- Pfad: `C:\Projects\AI-API-MVP\CLAUDE.md`

### Session-Handoff (nach dem Arbeiten)

- 2 Minuten am Session-Ende
- `docs/sessions/YYYY-MM-DD.md`
- Was gemacht, offen, naechste Schritte
- "Claude, schreib die Session-Zusammenfassung."

### Auto-Memory (Claude-intern)

- Claude Code schreibt sich selbst Notizen
- Begriffe, Muster, Praeferenzen
- Pfad: `C:\Users\User\.claude\projects\...\memory\MEMORY.md`
- Nicht manuell editieren

---

## Wissensbasis (ai-api-mvp Tree)

Der Tree `vault/trees/ai-api-mvp/` ist das **zentrale Projektgedaechtnis**.

- Alle Architektur-Entscheidungen stehen hier
- Neue Erkenntnisse werden hier eingetragen
- Bei jeder Session: Tree konsultieren vor dem Coden
- Pfad: `C:\Projects\AI ERP\vault\trees\ai-api-mvp\`

---

## Pre-Commit Checks (automatisch)

Bei jedem Commit laufen automatisch:
1. **Ruff** — Linting + Formatierung
2. **pyright** — Type-Check
3. **gitleaks** — Secrets-Scan
4. **pytest** — Tests

Konfiguration: `.pre-commit-config.yaml` im Projekt-Root.

---

## Wartung (alle 3 Monate)

- 30 Minuten, Kalender-Eintrag
- Pfade stimmen? APIs noch da? Docs aktuell?
- Externe API-Versionen noch supported?
- Tree-Nodes noch korrekt?

---

## DevMonitor (visuell)

Der DevMonitor zeigt den gesamten Prozess live:
- Oben: Gedaechtnis-Dateien gelesen (CLAUDE.md, MEMORY.md, Session)
- Mitte: DU → CLAUDE → CHECKS → GIT
- Unten: Session-Handoff geschrieben, MEMORY aktualisiert, BACKUP

Pfad: `C:\Projects\DevMonitor\`
Start: `DevMonitor.bat` auf dem Desktop

---

## Der Trick

Du brauchst keine Disziplin:
- CLAUDE.md → laedt automatisch
- Handoff → Claude schreibt es fuer dich
- Memory → Claude merkt sich Sachen automatisch
- Checks → laufen automatisch vor Commit
- Tree → ist die Single Source of Truth
- Wartung → Kalender erinnert dich
