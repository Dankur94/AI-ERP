# Von Odoo

| Prinzip | Wie wir es nutzen |
|---|---|
| Schmaler Kern + Module | Plattform-Kern ist minimal. Jedes Feature (Booking, Payment, Chat) = eigenes Modul |
| Bridge-Module | Wenn Laden Booking UND Payment hat → automatisch "Bezahlung bei Buchung" aktiv |
| DB pro Kunde | Jeder Laden hat isolierte Daten. Kein Leak. Einfach. |
| Community vor Enterprise | Erst kostenlos (T2 Laeden), monetarisieren spaeter |

**Referenz:** TinyERP → OpenERP → Odoo → 500M EUR / 12M+ Nutzer (2025)
