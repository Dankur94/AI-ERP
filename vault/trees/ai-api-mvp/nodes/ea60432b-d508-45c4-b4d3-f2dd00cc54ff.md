# Von Stripe

| Prinzip | Wie wir es nutzen |
|---|---|
| Geteiltes Datenmodell | Ein Datenmodell fuer alle Module — nicht jedes Modul hat eigene DB |
| Jedes neue Produkt folgt den Daten | Nicht raten was Laeden brauchen, sondern beobachten was am Rand passiert |
| Progressive Complexity | Laden sieht erstmal nur Profil. Booking erscheint wenn relevant. Nicht alles auf einmal. |
| Enterprise = anderes Packaging | Grosse Ketten bekommen denselben Code, andere Config |

**Referenz:** 7 Zeilen Code (2011) → 50% der Fortune 100 (2024)
