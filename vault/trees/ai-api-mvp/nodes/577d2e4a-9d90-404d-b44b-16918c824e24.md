# Go-to-Market

## Ueberblick

Kein Paid Marketing. Kein App Store Launch. Stattdessen: persoenlich, lokal, eine Vertrauenskette.

## Kernprinzip

Vertrauen ist die Waehrung. Kleine Ladenbesitzer vertrauen:
- Leuten die sie kennen
- Empfehlungen von anderen Ladenbesitzern
- Beweis statt Versprechen

## Was NICHT funktioniert

- Pitch-Deck mit Buzzwords
- "Ich baue eine Plattform"
- Irgendwas wo sie unterschreiben sollen
- Grosses Versprechen ohne Beweis

## Was funktioniert

- Du bist Stammkunde / aus dem Viertel
- Du loest EIN konkretes Problem gratis
- Mundpropaganda von anderem Laden
- "Probier mal, kostet nichts"
