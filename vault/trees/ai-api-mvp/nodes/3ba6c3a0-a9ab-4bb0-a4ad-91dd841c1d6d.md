# Strategie & Positionierung

## Ueberblick

| Dimension | Entscheidung |
|---|---|
| Ziel | Alles-in-einem Plattform (Option A — Shopify/WeChat) |
| Methode | Orchestrator (Option C — bestehende APIs zusammenbauen) |
| Kein Widerspruch | Ziel ist A, Bauweise ist C |

## Positionierung

"Eine Plattform fuer lokale Laeden — alles in einer App, null Setup."

Wir eliminieren den **IT-Menschen** den ein kleiner Laden normalerweise braucht (Webentwickler, App-Entwickler, System-Admin).

## Modul-Typen auf der Plattform

| Typ | Wer baut | Beispiel |
|---|---|---|
| Eigen (orchestriert) | Wir, aus bestehenden APIs | Zahlungen = Stripe API im Backend |
| Eigen (custom) | Wir, von Hand | Erste Kunden-Probleme perfekt loesen |
| Fremd | T1 Entwickler | Bauen auf unserer Plattform via API |

## Revenue-Modell (spaeter)

Inspiriert von Shopify: Wir verdienen wenn der Laden verdient (Transaktionsgebuehr). Nicht Abo-basiert.
