# Vertrauenskette & Erster Kontakt

## Erster Kontakt (Tueroeffner)

**Japsignal Property Agency Co., Limited**
- Property-Vermittler in Riviera Gardens
- Persoenlicher Kontakt vorhanden
- Kennt alle Ladenbesitzer die dort mieten
- Rolle: Nicht Kunde, sondern Tueroeffner

## Die Kette

```
Vermittler (persoenlicher Kontakt, Vertrauen)
    → erster Laden (gratis helfen, Beweis liefern)
        → zweiter Laden (Empfehlung vom ersten)
            → dritter Laden (Momentum)
                → ab 3-5 Laeden: App pitchen
```

## Vorgehen

1. Zum Vermittler gehen, normales Gespraech
2. Fragen: "Welcher Laden hier hat Muehe mit Kunden/Sichtbarkeit?"
3. Diesem einen Laden etwas Konkretes anbieten — gratis, klein, sofort nuetzlich
4. Wenn das klappt → Empfehlung zum naechsten

## Wichtig

- Nicht mit der App-Idee anfangen
- Erst ein konkretes Problem loesen
- MVP auf dem Handy zeigen koennen (nicht nur reden)
