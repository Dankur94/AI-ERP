# Zweite Welle (Payment, Chat, Bewertungen)

Sobald erster Laden live ist und der MVP-Kern laeuft:

## Payment (Stripe + FPS)

- Erst wenn Laden etwas verkauft/bucht
- Stripe: Karten, Alipay, WeChat Pay (3.4% + HK$2.35)
- FPS: Bank-zu-Bank, 0% Gebuehren (lokal dominant)
- Empfehlung HK: Beides zusammen

## Chat (Matrix, self-hosted)

- Laden ↔ Kunde Kommunikation
- 1:1 Nachrichten
- Self-hosted = $0, unbegrenzt
- Spaeter: AI antwortet fuer den Laden (Stufe 4)

## Bewertungen

- Social Proof, Vertrauen
- Sterne + kurzer Text
- Eigenbau (simpel, wenige DB-Tabellen)
- Vertrauen zwischen Laeden staerken

## SMS/OTP (Plivo)

- Telefonnummer-Verifizierung fuer Buchungen
- ~$0.02/SMS
- Erst wenn Fake-Buchungen ein Problem werden

## Bild-Upload (Cloudflare R2)

- Laden-Fotos, Menu-Bilder, Service-Bilder
- 10GB kostenlos, kein Egress
- Kompression via imgproxy
