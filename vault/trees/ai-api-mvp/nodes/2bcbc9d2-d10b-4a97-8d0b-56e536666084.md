# 4 — OBERFLAECHE (was Nutzer sehen)

Drei verschiedene Interfaces fuer drei verschiedene Nutzer-Typen.
**Chat-First** — T2 und T3 nutzen AI-Chat als primaeren Eingang, nicht klassische UIs.

## Voraussetzung

MODULE muessen funktionieren. Die Oberflaeche ruft nur die API auf — sie hat keine eigene Logik.

## Tech (gesetzt: 2026-05-06)

**Vue.js 3** als Framework fuer alle Frontends:
- Composition API + TypeScript
- PWA mit vite-plugin-pwa (Service Worker, Offline, Installierbar)
- WebSocket-Anbindung an FastAPI Gateway
- Mobile-First Design

Warum Vue.js: SFC Pattern (ein File pro Komponente), Chat-UI + Rich Cards natuerlich,
schnellstes Laden (<50KB Initial), Claude Code kennt es sehr gut.

## Die drei Eingaenge

| Wer | Was er sieht | Technik | Kern-UI |
|---|---|---|---|
| T3 (Endkunde) | Chat nach QR-Scan | Vue.js PWA, kein Login | AI-Chat + Rich Cards |
| T2 (Laden) | Chat + optionale Views | Vue.js SPA, Login | AI-Chat + Kalender/Stats |
| T1 (Entwickler) | API-Docs + Portal | Statische Docs + Dashboard | Kein Chat |

## Prinzip

- **Chat-First** — T2 und T3 sprechen mit AI, nicht mit Buttons
- **Oberflaeche ist duenn** — nur Darstellung, keine Business-Logik
- **Quick Actions** als Fallback (Buttons wenn AI down)
- Alles laeuft ueber die API (gleiche API die T1 nutzt)
- Wenn die API funktioniert, kann jeder eine eigene Oberflaeche bauen

## Frontend-Struktur (gesetzt)

```
web/
├── t3/                      # Endkunde
│   ├── App.vue
│   ├── views/
│   │   ├── ChatView.vue     # Hauptview — der Chat
│   │   └── ShopView.vue     # Profil nach QR-Scan
│   └── components/
│       ├── ChatMessage.vue
│       ├── ChatInput.vue
│       ├── SlotPicker.vue   # Rich Card: Slots waehlen
│       ├── BookingCard.vue  # Rich Card: Buchungsdetails
│       └── QuickActions.vue # Fallback wenn AI down
│
├── t2/                      # Shop-Owner
│   ├── App.vue
│   ├── views/
│   │   ├── ChatView.vue     # Gleicher Chat, andere Tools
│   │   ├── LoginView.vue
│   │   └── CalendarView.vue # Optional: Kalender-Ansicht
│   └── components/
│       ├── StatsCard.vue    # Rich Card: Umsatz
│       └── BookingList.vue  # Rich Card: Buchungsliste
│
└── shared/                  # Geteilt
    ├── composables/
    │   ├── useWebSocket.ts  # WebSocket Connection
    │   ├── useChat.ts       # Chat-Logik
    │   └── useAuth.ts       # Token Management
    └── components/
        ├── ChatBubble.vue
        └── LoadingDots.vue  # "AI denkt nach..."
```

~15 Dateien. Das ist das ganze Frontend.
