# 2 — KERN (Plattform-Fundament)

Das Fundament auf dem alle Module stehen. Baust du einmal richtig, profitiert alles danach.

## Was gehoert hierher

- **Datenmodell** — Wie Daten organisiert sind (shop_id als Key)
- **Gateway** — Der eine Eingang fuer alles
- **Queue** — Warteschlange pro Laden (keine Race Conditions)
- **Memory** — Das Gedaechtnis der Plattform (4 Schichten)
- **7 Schichten** — Was die Plattform fuer T2/T1 erledigt
- **T1 API** — Wie Entwickler zugreifen
