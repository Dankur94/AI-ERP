# MVP-Kern (Auth, Push, Suche, QR, Real-Time)

Was fuer den ersten funktionierenden Prototyp da sein muss:

## 1. Authentication (Supabase Auth)

- Laden-Login (Email/Phone)
- Kunden: kein Login noetig (QR → Session)
- Spaeter: Phone OTP fuer Kunden die buchen

## 2. Push Notifications (Firebase FCM)

- "Dein Termin morgen 14 Uhr" — Retention-Hebel
- Komplett kostenlos
- Web Push (kein App Store noetig)

## 3. Suche (SQLite FTS5)

- Kunde sucht Laden/Service
- Volltextsuche ueber Laden-Profile
- Kostenlos, performant, kein externer Service

## 4. QR-Code (segno + html5-qrcode)

**Der Schluesselbaustein** — loest das "kein Download" Problem:
1. Laden hat QR-Code an Kasse/Tuer
2. Kunde scannt mit Handy-Kamera
3. Web-App oeffnet — kein App Store, kein Login
4. Kunde sieht Profil, kann buchen

Reibung eliminieren (Muster 3). Stufe 3 Einstieg.

## 5. Real-Time (FastAPI WebSocket)

- Buchungsbestaetigung sofort
- Live-Updates fuer Laden ("Neue Buchung!")
- Nativ in FastAPI, $0 Kosten
