# Health-Check (Gruen oder Rot)

## Was es ist

Ein Befehl den du nach jeder Session tippst:

```bash
python health.py
```

## Was du siehst

```
✓ Server laeuft
✓ Datenbank erreichbar
✓ 14/14 Tests bestanden
✓ Tops Hairsalon Profil ladbar
✓ Buchung moeglich
✗ Payment fehlgeschlagen — Stripe Key abgelaufen
```

Kein Code lesen. Nur: laeuft alles oder nicht.

## Warum

Du codest nicht selbst. Du brauchst einen Weg zu pruefen ob Claude etwas kaputt gemacht hat. Ohne Code zu lesen, ohne Fehlermeldungen zu interpretieren.

## Was es prueft

- Server erreichbar?
- Datenbank verbunden?
- Alle Tests gruen?
- Pro Modul: Kern-Funktion geht? (z.B. "kann ein Profil laden")
- Externe APIs verbunden? (Stripe, etc.)

## Wann ausfuehren

- Nach jeder Claude-Session
- Vor jedem Commit (kann in pre-commit Hook)
- Wenn etwas sich "komisch anfuehlt"

## Aufwand

Einmal bauen (~1 Stunde), dann waechst es mit jedem Modul (jedes Modul fuegt 1-2 Checks hinzu).
