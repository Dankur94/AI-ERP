# Zielgruppen (3T)

## Die drei Typen

| Kuerzel | Typ | Rolle auf der Plattform |
|---|---|---|
| **T1** | Entwickler (B2B) | Baut Module auf der Plattform via API |
| **T2** | Laden (B2B) | Nutzt die Plattform, versteht keine Technik |
| **T3** | Endkunde (B2C) | Nutzt die App, merkt nichts von der Technik |

## Wie die Plattform fuer jeden aussieht

**T1 (Entwickler):**
- API + Dashboard
- 7 AI-Readiness-Schichten fertig implementiert
- Dokumentation + API-Key → sofort bauen
- Sandbox-Umgebung (fremder Code laeuft isoliert)

**T2 (Laden):**
- Simple UI, kein Setup
- 7 Schichten unsichtbar erledigt
- "Sag mir was du anbietest" → Plattform baut alles auf
- Progressive Complexity (sieht erstmal nur Profil, Rest erscheint wenn relevant)

**T3 (Endkunde):**
- Kein Download, kein Konto noetig
- QR-Code scannen → drin
- Spaeter: "Buche Haarschnitt Freitag 14h" → passiert (Stufe 4)

## Flywheel

T1 baut Module → T2 nutzt sie per Klick → T3 bekommt besseres Erlebnis → mehr T3 → mehr T2 → mehr T1
